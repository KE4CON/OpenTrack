## What it does

OpenTrack is where you record, organize, and work through bugs and problems for
one project or dozens. It covers the whole lifecycle — from "something's wrong"
to "fixed and closed" — for software projects and non-code projects alike.

## Features & functions

**Runs everywhere, one app**
- Native **desktop app** (Windows / macOS)
- **Web app** you can open from any browser on your network — including phones and tablets
- **REST API** for automation and integrations
- All three from a single codebase, so features and data stay in sync

**Near-zero setup, your data stays yours**
- Backed by a single **SQLite** file — no separate database server to install
- Scales up to SQL Server or PostgreSQL when you need it
- One-click **CSV / JSON export**, simple full-database backup
- **Import from MantisBT** — bring your existing issues across in minutes

**The full issue model** (familiar to MantisBT users)
- Status, severity, priority, reproducibility, resolution
- Categories, versions (affects / fixed-in), due dates, sticky/pinned, private issues
- Public and private notes, complete change history, file attachments
- Issue relationships (related, duplicate, parent/child, blocks)
- **Tags** and **custom fields** (text, number, date, pick-list)

**Built for how you actually work**
- **Cross-project dashboard** — open, overdue, and stale counts, by-severity breakdown, recent activity
- **Kanban board** view — move cards through the workflow (works on a tablet, too)
- **Quick-add capture** — log a problem in five seconds
- **Bug-hunt checklists** — build or import a per-project checklist, run it on an iPad or Android tablet, and turn any failure into a linked issue
- **Stale-issue surfacing** — nothing quietly rots
- **Bulk actions**, advanced search and filtering
- **Markdown with code blocks** — paste a stack trace and it reads properly

**Team-ready, security-first**
- Per-project roles and access control (Viewer → Reporter → Updater → Developer → Manager → Admin)
- Email notifications and issue monitoring/following
- Access rules enforced identically across the API and the web UI — they can't drift
- Passkey sign-in; 126 automated tests; built and reviewed with explicit security lenses

**Free & open source** — AGPL-licensed. No seats, no subscription, no telemetry.

## Who it's for

- **Solo developers and hobbyists** who want to track their own projects without
  standing up a database server or paying a monthly fee.
- **Small teams** that want self-hosted issue tracking they fully control.
- **Field / hardware / ham-radio and other non-software projects** — anything with
  "problems to track," not just code.
- **MantisBT users** wanting a modern, cross-device upgrade that imports their data.

## How to position it (why choose OpenTrack)

**vs. MantisBT** — Everything familiar, nothing dated: a native desktop app, a
tablet bug-hunt checklist, a live cross-project dashboard, Markdown, and no MySQL
to run. And it imports your MantisBT data, so switching is painless.

**vs. Jira / cloud trackers** — Free and self-hosted. No subscription, no seat
limits, no vendor lock-in, no data leaving your network. Works entirely on your
own LAN, even offline.

**vs. GitHub / GitLab Issues** — Works for non-code projects too, is private by
default, has a far richer field/workflow model, and runs on hardware you control.

## One-paragraph "about" (for a README)

as a native desktop app, a web app, and a REST API from one codebase, stores

tablet-friendly bug-hunt checklist — to the familiar MantisBT feature set. Import
